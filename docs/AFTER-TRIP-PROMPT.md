# Prompt สำหรับคุยกับ Claude หลังกลับจากจีน

ไฟล์นี้มี 2 ส่วน: **แบบจดระหว่างทริป** และ **prompt ที่คัดลอกไปวางได้เลย** ตอนกลับมา

---

## 1. ระหว่างทริป: จดทุกคืน (2 นาที)

จดใน Notes ของมือถือก็ได้ ไม่ต้องสวย ขอแค่มี 3 หัวข้อนี้

```
วันที่ ...  เมือง ...

ใช้ได้ผล (พูดแล้วเขาเข้าใจ):
-

พูดแล้วเขาไม่เข้าใจ (ผมพูดว่าอะไร / เขาทำหน้ายังไง / สุดท้ายแก้ยังไง):
-

เขาพูดแล้วผมฟังไม่ออก (สถานการณ์ / ถ้าจำเสียงได้เขียนตามที่ได้ยิน):
-

อยากพูดแต่ไม่รู้คำ:
-
```

ก่อนกลับ ให้กดส่ง log จากแอปหนึ่งครั้ง (ฉัน → 🐞 รายงานปัญหา → แชร์ไฟล์ log)

---

## 2. หลังกลับมา: คัดลอกทั้งกล่องนี้ไปวาง

เปิด Claude Code ที่โฟลเดอร์ `D:\chiana 2` แล้ววางข้อความนี้ แนบไฟล์ log และบันทึกทริปไปด้วย

```
ผมกลับจากจีนแล้วครับ โปรเจกต์คือแอป Panda (พูดจีนรอดใน 20 วัน) ในโฟลเดอร์นี้
repo: github.com/Grandthing/panda-chinese · เว็บจริง: https://grandthing.github.io/panda-chinese/
เป้าหมายยังเหมือนเดิม: คนที่เรียนแอปนี้ต้องพูดภาษาจีนได้จริง

ก่อนเริ่ม ช่วยอ่านไฟล์เหล่านี้เพื่อรู้สถานะล่าสุด:
- README.md (โครงสร้างไฟล์ วิธีทดสอบ วิธีปล่อยเวอร์ชัน)
- docs/AFTER-TRIP-PROMPT.md (ไฟล์นี้)
- js/vocab.js และ tools/make_vocab.py (โหมด "คลังคำ 500" ที่ยังแยกอยู่)
- tests/run.mjs (ชุดทดสอบ)

สิ่งที่ผมแนบมา:
1. บันทึกระหว่างทริป: [วางข้อความ หรือบอกที่อยู่ไฟล์]
2. ไฟล์ log จากแอป: [ที่อยู่ไฟล์ panda-log-*.txt]

งานที่อยากให้ทำ เรียงตามลำดับ:

1. สรุปจากบันทึกและ log ก่อน ยังไม่ต้องแก้โค้ด
   - วลีไหนใช้ได้ผลจริง วลีไหนพูดแล้วเขาไม่เข้าใจ (เป็นเพราะเสียงผม หรือเพราะวลีไม่เป็นธรรมชาติ)
   - คนจีนตอบอะไรที่ผมฟังไม่ออก และแอปยังไม่มีสอน
   - คำที่ผมอยากพูดแต่ไม่รู้
   - ระบบตรวจเสียงให้ผ่าน/ไม่ผ่านตรงกับที่คนจีนเข้าใจจริงไหม
   แล้วเสนอแผนแก้ให้ผมดูก่อน

2. รวมโหมด "คลังคำ 500" เข้ากับหลักสูตรหลัก
   - ตอนนี้ความคืบหน้าเก็บแยกใน S.vocab และไม่อยู่ในระบบทบทวน (SRS) ของ 20 วัน
   - ต้องการ: คำในคลังคำเข้าระบบทบทวนเดียวกัน, อยู่ในการ์ดพูด, ใช้ในโหมดประกอบประโยคและสถานการณ์ได้
   - ห้ามทำให้ความคืบหน้าเดิมของผมหาย (ทั้ง 20 วันและคลังคำที่เรียนไปแล้ว)
   - เกณฑ์ "พูดเพี้ยนแต่คนจีนเข้าใจ = ผ่าน" ให้คงไว้ แล้วปรับตามสิ่งที่เจอจริงในทริป

3. เพิ่มเนื้อหาจากทริป
   - วลีที่ผมต้องใช้แต่ไม่มีในแอป
   - คำตอบของคนจีนที่เจอจริง ใส่ในโหมด "คนจีนตอบว่าอะไร"
   - สถานการณ์ที่เจอจริง ใส่ในโหมด "พูดเองตามสถานการณ์"

4. เสนอระยะ 3 ให้ผมตัดสินใจ (ยังไม่ต้องทำ)
   - คู่สนทนา AI ที่ตอบไม่ซ้ำ
   - ตัวตรวจการออกเสียงระดับพยัญชนะ
   - บอกค่าใช้จ่ายและสิ่งที่ต้องมี (เซิร์ฟเวอร์ / API key) ให้ชัด

วิธีทำงานที่ผมต้องการ:
- ตอบเป็นภาษาไทย
- แก้อะไรแล้วต้องรัน npm test ให้ผ่านก่อนขึ้น GitHub
- เปลี่ยนเกณฑ์ตรวจเสียงเมื่อไหร่ ให้บอกว่าผลจาก log เก่าเปลี่ยนกี่ครั้ง (npm run test:update แล้วดู diff)
- ปล่อยเวอร์ชัน: แก้ APP_VERSION ใน js/core.js และ VERSION ใน sw.js แล้ว push แล้วตรวจว่าเว็บจริงขึ้นเวอร์ชันใหม่
- บอกตรง ๆ ว่าอะไรทดสอบแล้ว อะไรยังไม่ได้ทดสอบบน iPhone จริง
- เพิ่ม log ของทริปเข้าชุดทดสอบด้วย: python tools/make_sr_fixture.py <โฟลเดอร์ log>
```
