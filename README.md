# พูดจีนรอดใน 20 วัน 🐼

เว็บแอป (PWA) เรียนพูดภาษาจีนกลางแบบเกมเลื่อนเลเวล สำหรับคนไทยที่อ่านตัวจีนไม่ออก เป้าหมายคือพูดเอาตัวรอดตอนไปเที่ยวจีนได้ใน 20 วัน
เรียนผ่าน pinyin + คำอ่านไทย + ความหมายไทย มีตัวจีนตัวเล็กไว้ชี้ให้คนจีนดู · ไม่มี backend · ไม่มี API key · เก็บความคืบหน้าในเครื่อง

รายละเอียดการออกแบบทั้งหมดอยู่ใน [SPEC.md](SPEC.md)

## ใช้งานบน iPhone

1. เปิดลิงก์ GitHub Pages ของ repo นี้ใน **Safari**
2. แตะปุ่มแชร์ → **เพิ่มลงหน้าจอโฮม** → เปิดจากไอคอนแพนด้าทุกครั้ง
3. (แนะนำ) ดาวน์โหลดเสียงจีนคุณภาพสูงฟรี: ตั้งค่า → การช่วยการเข้าถึง → เนื้อหาที่พูด → เสียง → จีน (จีนแผ่นดินใหญ่)
4. (สำหรับระบบตรวจคำพูด) ตั้งค่า → ทั่วไป → แป้นพิมพ์ → เปิด "การป้อนตามคำบอก"

## เจอบั๊ก → ส่ง log ทาง LINE

แอปจดบันทึกการใช้งานล่าสุด 400 บรรทัดไว้ในเครื่อง (หน้าที่เปิด, บทเรียน, คำตอบ, สิ่งที่ระบบได้ยิน, ผลตรวจวรรณยุกต์, ข้อผิดพลาด)
เปิดได้จาก แท็บ "ฉัน" → 🐞 รายงานปัญหา หรือจากป้ายแจ้ง "เกิดข้อผิดพลาด" ที่เด้งขึ้นเอง

- **💬 ส่งไป LINE** — เปิด LINE พร้อมข้อความ log ล่าสุด (ตัดให้สั้นพอส่งเป็นข้อความ) เลือกแชทแล้วส่ง
- **📎 แชร์ไฟล์ log ทั้งหมด** — ส่งเป็นไฟล์ .txt ผ่านเมนูแชร์ของ iPhone (เลือก LINE ได้)
- **📋 คัดลอก log** — คัดลอกไปวางที่ไหนก็ได้

log ไม่มีข้อมูลส่วนตัว นอกจากรุ่นเครื่อง ผลการเรียน และคำภาษาจีนที่ระบบได้ยิน

## รันในเครื่อง

```bash
python -m http.server 5173
```

แล้วเปิด http://localhost:5173 — ต้องเปิดผ่านเซิร์ฟเวอร์ (เปิดไฟล์ `index.html` ตรง ๆ จะโหลดบทเรียนไม่ได้)
เปิด http://localhost:5173/?lint เพื่อตรวจเนื้อหา, `?seed=123` เพื่อสุ่มแบบฝึกแบบเดิมซ้ำได้

| `js/audio.js` | เสียงเอฟเฟกต์, เสียงเครื่อง, เสียงอัด |

| `js/ui.js` | ชิ้นส่วนหน้าจอและทุกหน้า (เรียน, การ์ดพูด, ทบทวน, ฉัน, ตั้งค่า) |
| `js/lesson.js` | ตัวเล่นบทเรียน: หนึ่งฟังก์ชันต่อแบบฝึกหนึ่งแบบ |
| `js/practice.js` | ประกอบประโยคเอง, พูดเองตามสถานการณ์ + สอบ, คนจีนตอบว่าอะไร, แยกเสียงคล้าย |
| `js/vocab.js` | โหมดแยก "คลังคำ 500" (หลังจบ 20 วัน) |
| `js/main.js` | router และการเปิดแอป |
| `content/vocab.json` | คำ 500 คำพร้อมประโยคตัวอย่าง (สร้างจาก `tools/vocab_words.py` ด้วย `tools/make_vocab.py`) |
| `docs/AFTER-TRIP-PROMPT.md` | แบบจดระหว่างทริป และ prompt สำหรับทำงานต่อหลังกลับมา |
| `content/patterns.json` | โครงประโยค, สถานการณ์, คำตอบของคนจีน, คู่เสียงคล้าย (สร้างจาก `tools/make_patterns.py`) |
| `tests/run.mjs` | ชุดทดสอบอัตโนมัติ (`npm test`) |
| `style.css` | หน้าตา (มีโหมดมืด) |
| `content/units.json` | **เนื้อหาทั้งหมด** — คำ วลี บทเรียน บทสนทนา |
| `sw.js` / `manifest.webmanifest` | PWA ออฟไลน์ + ติดตั้ง |

## เพิ่มบทเรียน (ไม่ต้องแก้โค้ด)

1. เพิ่มคำใน `items` ของ `content/units.json` — `hanzi`, `pinyin` (มีเครื่องหมายวรรณยุกต์), `thai` (เขียนตามเสียงพูดจริง จำนวนคำเท่ากับ pinyin), `meaning`, `cat`
2. ใส่ id ของคำใน `newItems` ของบทที่ต้องการ (หรือสร้าง unit ใหม่ใน `units`)
3. เปลี่ยน `contentVersion`
   - แบบฝึกฟังตัวเลข (`content/numbers.json`) สร้างจาก `python tools/make_numbers.py` — แก้ตัวเลข/สถานการณ์ในไฟล์นั้นแล้วรันใหม่
   - ความหมายของแต่ละคำในวลี (`content/glossary.json`) สร้างจาก `python tools/make_glossary.py` — เพิ่มคำ/ตัวอักษรใหม่ในไฟล์นั้น (สคริปต์จะแจ้งถ้ามีตัวจีนในบทเรียนที่ยังไม่มีความหมาย)
4. สร้างเสียงอัดของคำใหม่: `python -m pip install edge-tts` แล้ว `python tools/make_audio.py` (สร้างเฉพาะไฟล์ที่ยังไม่มี; คำที่ไม่มีเสียงอัดจะใช้เสียงเครื่องแทนอัตโนมัติ)
5. เปิด `?lint` ให้ขึ้นว่า "ไม่พบปัญหา"

แบบฝึกถูกสร้างอัตโนมัติจากรายการคำ · ใส่ `reject` (คำที่ต่างแค่วรรณยุกต์) เพื่อให้ระบบบอกได้ว่าวรรณยุกต์ผิด · ใส่ `dialogs` เพื่อเพิ่มบทสนทนาจำลอง

   - โครงประโยค / สถานการณ์พูดเอง / คำตอบของคนจีน / คู่เสียงคล้าย (`content/patterns.json`) สร้างจาก `python tools/make_patterns.py` แล้วรัน `make_glossary.py` และ `make_audio.py` ต่อ

   - คลังคำ 500 (`content/vocab.json`): เพิ่ม/แก้คำใน `tools/vocab_words.py` (คำ | ความหมาย | ประโยคตัวอย่าง | ความหมายประโยค) แล้วรัน `python tools/make_vocab.py` (ต้องมี `pip install pypinyin`) — pinyin และคำอ่านไทยสร้างให้อัตโนมัติ ถ้าอ่านผิดให้ใส่ pinyin เองเป็นช่องที่ 5 · เสียงของคลังคำอัดแค่ 2 เสียงเพื่อให้ไฟล์เล็ก

เมื่อแก้ `js/*.js` / `style.css` / `index.html` ให้เปลี่ยน `VERSION` ใน `sw.js` และ `APP_VERSION` ใน `js/core.js` ด้วย แอปจะขึ้นปุ่ม "อัปเดต"

## ทดสอบก่อนปล่อย

```
npm install      # ครั้งแรกครั้งเดียว (ใช้ jsdom)
npm test
```

ชุดทดสอบเปิดแอปจริงใน jsdom แล้วตรวจ 3 อย่าง:

1. เนื้อหาโหลดได้และ `lintContent()` ไม่พบปัญหา
2. ผลการพูดจาก log จริงของเครื่อง (`tests/fixtures/sr-attempts.json`) ได้ผลผ่าน/ไม่ผ่านเหมือนเดิม — ถ้าตั้งใจเปลี่ยนเกณฑ์ ให้รัน `npm run test:update` แล้วดู diff ของ `sr-golden.json`
3. เล่นทุกบท ทุกด่าน ทุกโหมดฝึก ตั้งแต่ข้อแรกจนจบโดยกดปุ่มจริง ต้องไม่มี error

เพิ่มผลการพูดจาก log ใหม่: `python tools/make_sr_fixture.py <โฟลเดอร์ที่มี panda-log-*.txt>` แล้ว `npm run test:update`
